# 验证范围

## 已验证

- 前端生产构建、单位换算、完整分页与跳转、调整边界、自动下载策略、寄存器与寿命解码。
- 系统盘保护、身份变化、范围校验、同盘复制、路径越界、符号链接逃逸、流式校验和取消。
- 临时 Linux 状态中的密码边界、随机盐、旧哈希迁移、Cookie、CSRF、限速。
- 临时目录中的选择性缓存清理、活跃任务和下载保护、文件变化、孤立暂存和完整历史列表。
- 自建临时镜像与 loop 中的 GPT/MBR、格式化、ext4 扩缩、文件/字节编辑、克隆、备份恢复及 HTTP 流式传输。
- 真实设备 eMMC 信息与只读读取、BOOT 软件保护恢复，网页及服务开机启动。
- 桌面/手机导航分组、系统深浅色切换、手动主题与刷新保持。
- 新部署检查中的忙任务拒绝、损坏任务数据库拒绝及发布包文件清单。

## 边界

root 集成测试需要 loop 和挂载能力，只操作自建临时设备。CI 默认运行构建、Python/前端测试、Shell 检查、发布打包，以及 CLI 的临时 loop 磁盘集成测试；原有完整磁盘和 HTTP 流式测试仍按需单独运行。

尚未完成插入真实 USB 后的整盘克隆验收；没有覆盖所有厂商 eMMC、所有发行版及断电中途的硬件行为。新安装器需在目标发行版核对环境；不能将部署前检查等同于全新系统实装验收。

完整备份不含 RPMB 认证密钥和厂商私有配置。仓库不含具体设备的 CID、UUID、串口日志、密码或临时部署密钥。磁盘写入前仍须使用者核对目标。

## CLI 1.1.0

新增 14 项 CLI 测试，覆盖精确单位换算、权限、请求预览、设备身份、原始字节摘要、流式分帧和失败时不覆盖文件。

在 Linux 上使用两个独立临时 loop 镜像和真实 worker socket 运行 CLI 子进程，验证 GPT 创建、ext4 格式化及扩容、分区文件编辑/下载与路径越界拒绝、字节写入/回退/完整范围导出、整盘克隆、gzip 流式备份/导入/恢复和任务/上传缓存清理。恢复后比对原始镜像 SHA-256。测试仅写临时镜像，不修改真实 eMMC。

当前设备已通过新版安装器升级至 1.1.0，管理员认证文件摘要保持不变。通过真实串口终端执行 CLI 版本查询和 BOOT 字节预览；用户区及两个 BOOT 区各读取 64 字节，两个文件系统分区只读列目录，BOOT `force_ro` 均为 1。网页和 worker 服务正常运行。部署检查增加 Linux TCP TIME_WAIT 与真实监听端口的区分测试，避免升级停止 Web 后误判端口占用。

## 独立应用升级 1.2.1

CI [v1.2.1 发布运行](https://github.com/JasonYANG170/eMMC-Studio/actions/runs/37015393192) 已通过格式、前端构建、前端断言、Python 检查、真实 CLI/worker loop 集成和 ShellCheck，发布官方签名升级包、部署包及校验清单。新增签名/升级测试在 Linux 执行 31 项，认证与 CSRF 测试执行 10 项。

验证有效签名、篡改签名、未知签名公钥、错误 SHA-256、平台不兼容、最低版本、禁止降级、同版本显式重装、缺文件、路径越界、重复文件、符号链接与解压容量上限；验证安装子进程、失败状态清理、存储忙碌拒绝、未完成上传、空间不足、升级冲突和服务重启中断状态。真实 loop 测试验证 root 对端身份限制、冻结期间拒绝新磁盘任务及解除冻结后的恢复。

真实设备通过 CLI 在线检查、官方签名包在线安装、1.2.0 → 1.2.1 升级、本地包导入和同版本重装；篡改签名包在安装前被拒绝。升级前后管理员文件和 BOOT0/BOOT1 全区 SHA-256 均一致，BOOT force_ro 均为 1。用户区和两个文件系统分区仅进行只读验收，未覆盖内容。三个服务均 active / enabled。

浏览器验证独立升级页面和官方在线版本检测。浏览器扩展未授予本地文件访问权限，文件选择自动化受限，实际本地导入通过 CLI 验收；前后端使用相同签名验证与安装服务。未对真实设备注入 systemd 启动失败或突然断电，故自动回滚只完成安装器逻辑审查和升级失败状态测试，不能视为真实断电恢复验收。
