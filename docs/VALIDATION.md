# 验证范围

## 已验证

- 前端生产构建、单位换算、完整分页与跳转、调整边界、自动下载策略、寄存器与寿命解码。
- 系统盘保护、身份变化、范围校验、同盘复制、路径越界、符号链接逃逸、流式校验和取消。
- 临时 Linux 状态中的密码边界、随机盐、旧哈希迁移、Cookie、CSRF、限速。
- 临时目录中的选择性缓存清理、活跃任务和下载保护、文件变化、孤立暂存和完整历史列表。
- 自建临时镜像与 loop 中的 GPT/MBR、格式化、ext4 扩缩、文件/字节编辑、克隆、备份恢复及 HTTP 流式传输。
- 真实设备 eMMC 信息与只读读取、BOOT 软件保护恢复，网页及服务开机启动。
- 桌面/手机导航分组、系统深浅色切换、手动主题与刷新保持。
- 新部署检查中的忙任务拒绝、损坏任务数据库拒绝及发布包文件清单。

## 边界

root 集成测试需要 loop 和挂载能力，只操作自建临时设备。CI 默认运行构建、非破坏性 Python/前端测试、Shell 检查和发布打包，不在普通托管 CI 默认执行 root 磁盘集成测试。

尚未完成插入真实 USB 后的整盘克隆验收；没有覆盖所有厂商 eMMC、所有发行版及断电中途的硬件行为。新安装器需在目标发行版核对环境；不能将部署前检查等同于全新系统实装验收。

完整备份不含 RPMB 认证密钥和厂商私有配置。仓库不含具体设备的 CID、UUID、串口日志、密码或临时部署密钥。磁盘写入前仍须使用者核对目标。
