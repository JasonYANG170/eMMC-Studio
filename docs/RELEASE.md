# eMMC Studio 1.1.0

新增串口/SSH 命令行管理，安装后直接使用 `sudo emmc-studio --help`。

- CLI 共用现有 worker 的系统盘保护、磁盘互斥、BOOT 临时解锁和持久化任务。
- 磁盘/系统信息、分区、文件、原始字节、克隆、备份恢复、任务和缓存管理。
- 精确单位换算、JSON 输出、后台任务、请求预览及实时进度。
- 范围、文件及完整备份直接流式输出；下载校验成功后才保存最终文件。
- 无需网页登录；依赖 Linux 管理员权限，不重置已有网页账号。

保留网页管理功能：

- 中文仪表盘、磁盘详情与 eMMC 寄存器解析。
- GPT/MBR 管理、ext4 调整、文件与 HEX/ASCII 编辑。
- 克隆、备份恢复、浏览器流式下载、任务与缓存管理。
- 系统盘保护、BOOT 临时解锁、普通用户 Web 与受限 root 工作进程。
- 系统主题同步、手机布局和导航分组。
- 一键部署、手动/源码安装教程、自动构建及校验。

安装包含构建后的网页，设备不用 Node.js。无默认密码，首次安装用终端一次性设置码创建管理员。部署要求和操作边界请查看 README。
