# eMMC Studio 1.2.2

- 在读取未签名包头时限制内存与解压范围，提前拒绝超大或 PAX 扩展头。
- 修复服务重启后的连接提示，自动重连并清除已恢复的网络错误。
- 新增独立应用升级服务，Web 与串口/SSH CLI 均支持在线检测、在线升级和本地导入。
- CI 发布 Ed25519 签名升级包，离线验证签名、版本、平台和 SHA-256。
- 安装前禁止新磁盘任务，拒绝忙碌状态；保留管理员、备份和记录，启动失败尝试回滚。
- 通过应用升级页面或 `sudo emmc-studio upgrade check` 使用；旧版先运行部署脚本初始化升级服务。

在线/本地升级使用 **eMMC-Studio-update.tar.gz**；首次部署使用 **eMMC-Studio.tar.gz**。操作说明见仓库 docs/UPGRADE.md。
